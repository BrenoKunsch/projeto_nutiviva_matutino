 # NutriViva
 ## Sobre o Projeto
A **Nutriviva** é um projeto de site voltado á alimentação saudável, com objetivo de compartilhar informações sobre a importância de manter hábitos alimentares equilibrados. A proposta é apresentar conteúdos que ajudem os usuários a compreender melhor a relação entre alimentação, saúde e qualidade de vida.
## Objetivo
O principal objetivo do NutriViva é icentivar a adoção de hábitos alimentares mais saúdavies por meio de informações acessíveis e educativas. O projeto busca mostrar como uma alimentação equilibrada pode contribuir para o bem-estar, a saúde e a melhoria da qualidade de vida.
## Tecnologias utilizadas
HTML: utilizado para estruturar o conteúdo e organizar os elementos das páginas do site.
CSS: responsável pela aparência visual, pelas cores, pelos estilos e pela organização dos elementos.
## Funcionalidades
* Apresentação de conteúdos relacionados à alimentação saudável e aos hábitos alimentares.
* Organização das informações em diferentes seções, ajudando a entender melhor o assunto apresentado.
* Organização visual agradável, proporcionando uma navegação mais simples para as pessoas.
* Disponibilização de informações que incentivam escolhas alimentares mais equilibradas.
## Desenvolvedores 
O projeto foi desenvolvido por estudantes, com a colaboração dos integrantes na criação, na organização das informações e na construção do site. Cada etapa contribuiu para o desenvolvimento das habilidades de planejamento, criatividade e programação.
## Contexto acadêmico
O NutriViva foi desenvolvido como parte de uma atividade do curso de tecnico em informática, com o propósito de colocar em prática os conhecimentos adquiridos durante os estudos de tecnologia e desenvolvimento web. Além de trabalhar com a criação de sites, o projeto aborda um tema importante para a saúde e o bem- estar da sociedade.
